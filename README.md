## 🌎 What is SYNC?

The person you're looking for might already be in the same room.

At hackathons, universities, conferences, and events, people are surrounded by potential teammates, mentors, friends, and collaborators — but there is no easy way to know who they should meet.

**SYNC changes that.**

Tell SYNC what you're looking for, discover relevant people nearby, send a SYNC request, and connect when the interest is mutual.

> **Technology starts the connection. People take it from there.**

---

## ⚡ How It Works

1. **Create your profile**
   Add your skills, interests, and what you want to learn or offer.

2. **Tell SYNC what you're looking for**
   For example:
   *“I want to learn Python.”*
   *“I need someone who knows hardware.”*

3. **Discover people nearby**
   SYNC uses proximity and profile information to help find relevant people around you.

4. **Send a SYNC request**
   Found someone interesting? Request to connect.

5. **It's a SYNC!**
   When both people accept, the connection is unlocked.

6. **Meet & Chat**
   View their profile, start a conversation, and turn the digital connection into a real one.

## 🔐 Privacy

SYNC is built around **mutual consent**.

Before a connection is accepted, SYNC is designed to avoid exposing unnecessary personal or precise location information.

The goal is simple:

**Help people discover each other without turning proximity into surveillance.**

---

## ⌚ SYNC Band

Our vision also includes the **SYNC Band** — a minimal, screenless wearable designed to make real-world discovery even more natural.

The Band is designed to work with the SYNC ecosystem using proximity detection and subtle feedback, allowing technology to stay in the background while people connect in the real world.

# 🚀 Build & Run Instructions

## Requirements

Before running SYNC locally, make sure you have:

* Node.js
* npm
* Git

## 1. Clone the repository

```bash
git clone https://github.com/StellaLeoni2008/sync-connect.git
```

## 2. Enter the project

```bash
cd sync-connect
```

## 3. Install dependencies

```bash
npm install
```

## 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
